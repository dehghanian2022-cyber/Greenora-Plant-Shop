# 🌿 Greenora — Plant & Garden Shop

Greenora is a modern and responsive plant shop website built with **HTML, CSS, and JavaScript**.

The project was created as a frontend practice project to improve my skills in building clean layouts, responsive designs, product cards, and simple interactive features.

## ✨ Features

* 🌱 Responsive design
* 🪴 Plant product cards
* 🛒 Simple shopping cart counter
* ❤️ Favorite buttons
* 📩 Newsletter form
* 📱 Mobile-friendly layout
* ✨ Hover effects and transitions

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🎨 Design

Greenora uses a natural green color palette with a clean and simple layout inspired by modern plant stores.

The website is designed to work on:

* 💻 Desktop
* 📱 Tablet
* 📱 Mobile

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
